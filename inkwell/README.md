# The Ink Well: מיני־משחק הדייג של The Unwritten

התיקייה הזאת מכילה את כל מה שצריך כדי להכניס את The Ink Well למשחק:

- **`GUIDE.md`**: מדריך ההכנסה, שלב אחרי שלב, בעריכות קטנות ומעוגנות לקובץ המאסטר. הוא כתוב באנגלית, כי הוא מיועד לסשן של Claude שפתוח אצלך על המחשב עם `the-unwritten-source.jsx`.
- **`assets/img/`**: כל הציורים החדשים (23 קבצי WebP), בשמות שהמשחק יקרא להם דרך `ART`.
- **`prototype/inkwell.html`**: אב־הטיפוס המלא. אפשר לפתוח אותו בדפדפן ולשחק. המנוע שבתוכו הוא הבסיס למסך הבאר במשחק.

## איך מתחילים

1. להוריד את התיקייה `inkwell` למחשב.
2. לפתוח סשן של Claude בתיקייה של המשחק.
3. לכתוב לו: "קרא את `inkwell/GUIDE.md` ותתחיל משלב 1. אחרי כל שלב תבדוק שהמשחק עולה ועובד, ורק אז תמשיך."

מומלץ לעבור שלב אחרי שלב ולבדוק במשחק בין שלב לשלב, ולא להכניס הכל בבת אחת.
